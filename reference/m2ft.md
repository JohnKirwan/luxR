# Convert metres to feet.

Vectorised; passes through `NA`.

## Usage

``` r
m2ft(z)
```

## Arguments

- z:

  Depth or distance in metres.

## Value

Numeric vector in feet.

## See also

[`ft2m`](https://johnkirwan.github.io/luxR/reference/ft2m.md)

## Examples

``` r
m2ft(30)
#> [1] 98.4252
```
