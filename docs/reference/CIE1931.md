# CIE Photopic Luminous Efficiency Function

The CIE 1931 photopic luminous efficiency function V(lambda), also
called the standard observer luminosity curve, from CIE 018:2019
Table 1. Tabulated at 1 nm intervals from 360 nm to 830 nm, with its
peak at 555 nm.

## Usage

``` r
CIE1931
```

## Format

A data frame with 471 rows and 2 columns:

- lambda:

  Wavelength in standard air, in nm (360-830, step 1).

- W:

  V(lambda), dimensionless sensitivity from 0 to 1.

## Source

International Commission on Illumination (CIE), *CIE spectral luminous
efficiency for photopic vision*, DOI:
[doi:10.25039/CIE.DS.dktna2s3](https://doi.org/10.25039/CIE.DS.dktna2s3)
, licensed CC BY-SA 4.0.

## Details

Generated by `data-raw/build_cie_efficiency_data.R` from the
checksum-pinned CIE CSV and companion metadata. Source URLs, DOI,
checksums, retrieval date, standard, and license are stored as
data-frame attributes under `"luxR.provenance"`.
