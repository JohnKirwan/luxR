# CIE Scotopic Luminous Efficiency Function

The CIE scotopic luminous efficiency function V'(lambda) for night
vision, from CIE 018:2019 Table 2. Tabulated at 1 nm intervals from 380
nm to 780 nm, with its peak at 507 nm. Used by
[`scotopic_lux`](https://johnkirwan.github.io/luxR/reference/scotopic_lux.md).

## Usage

``` r
CIE_scotopic
```

## Format

A data frame with 401 rows and 2 columns:

- lambda:

  Wavelength in standard air, in nm (380-780, step 1).

- W:

  V'(lambda), dimensionless sensitivity from 0 to 1.

## Source

International Commission on Illumination (CIE), *CIE spectral luminous
efficiency for scotopic vision*, DOI:
[doi:10.25039/CIE.DS.gr6w4b5g](https://doi.org/10.25039/CIE.DS.gr6w4b5g)
, licensed CC BY-SA 4.0.

## Details

Generated by `data-raw/build_cie_efficiency_data.R` from the
checksum-pinned CIE CSV and companion metadata. Source URLs, DOI,
checksums, retrieval date, standard, and license are stored as
data-frame attributes under `"luxR.provenance"`.
