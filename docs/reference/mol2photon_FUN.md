# Converts photon number in moles or similar to n.

Converts photon number in moles or similar to n.

## Usage

``` r
mol2photon_FUN(value, molar_unit = NULL)
```

## Arguments

- value:

  The value to be converted to photon number.

- molar_unit:

  The metric used, e.g. moles or micromoles.

## Value

The value in photons.
